# Audience / Voice Matrix

Before the first sentence, fix four dials — guess and proceed if the user
did not specify, but state the guess:

- AUDIENCE: who reads this and what they already know. Determines assumed
  vocabulary and how much is explained.
- PURPOSE: what the reader should be able to DO after reading. Every section
  earns its place against this.
- FORMAT + LENGTH: README / release note / tutorial / announcement / spec;
  and a target size. Length is a constraint, not an aspiration.
- VOICE: register (formal↔plain), person (2nd for docs), tense (present for
  behavior), energy (calm for reference, brisk for guides).

Calibration table by type:
- Reference docs → present tense, 2nd person, imperative, no narrative.
- Tutorials → 2nd person, step-numbered, every step has a visible result.
- Release notes → what changed, why it matters, what breaks, migration path;
  breaking changes never omitted or softened.
- Announcements → lead with the outcome for the reader, proof second, no
  marketing adjectives unless requested.

Edit pass checks against the dials: cut anything the audience already knows or
the purpose does not need; verify register consistency; replace every
"simply/just/easily" (they lie to the reader who is stuck).
