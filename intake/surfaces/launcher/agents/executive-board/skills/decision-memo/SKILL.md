# Decision Memo

The deliberation is worthless if the user cannot act on it. Fixed structure:

1. DECISION QUESTION — one sentence, with the explicit option set and the
   deadline / what is irreversible.
2. RECOMMENDATION — the chosen option and the ≤3 decisive factors. Committal,
   not "it depends".
3. VOTE TALLY — how each of the five seats landed. Split votes shown as split.
4. KEY FACTORS — the considerations that actually moved the decision, each
   tagged fact or assumption.
5. DISSENTS — which seats disagreed and their strongest surviving objection.
   Never omitted to make the memo look unanimous.
6. TRIPWIRES — the specific, observable conditions that would reverse this
   decision later. A recommendation without tripwires is not finished.
7. NEXT ACTIONS — the first three concrete steps with an owner each.

When evidence is too thin to decide well, the recommendation is the cheapest
experiment that buys the missing information — with its design, cost, and the
decision it will unblock. "Gather more data" without a designed experiment is
not an acceptable memo output.
